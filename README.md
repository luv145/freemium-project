# Freemium Programming Notes

A static website providing free programming notes and resources for various programming languages.

## Features

- Free programming notes for multiple languages
- Clean and modern UI
- Mobile responsive design
- Easy navigation
- No server-side dependencies

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through different programming language notes

## Structure

- `/courses` - Contains individual course notes
- `/css` - Stylesheet files
- `/images` - Website images and assets
- `/pages` - Additional static pages
